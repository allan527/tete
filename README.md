# Texas Finance

Personal Loan Management Dashboard for Uganda built with React + TypeScript (frontend-only).

## Run

```bash
npm install
npm run dev
```

## Features implemented

- Dashboard KPIs with UGX formatting
- Client onboarding with 20% monthly interest over 30-day term
- Payment recording with auto status updates
- Cashbook and owner capital synchronization
- Owner-only route guard for Data View
- Frontend-only local data flows (no backend or database integration)
