# Texas Finance

Personal Loan Management Dashboard for Uganda built with React + TypeScript and Supabase.

## Run

```bash
npm install
npm run dev
```

## Features implemented

- Dashboard KPIs with UGX formatting
- Client onboarding with 20% monthly interest over 30-day term
- Payment recording with auto status updates
- Cashbook and owner capital synchronization
- Owner-only route guard for Data View
- Supabase Edge Function (Hono) CRUD + Africa's Talking SMS endpoint
